## Уровни основного текста

Вместо двенадцати прозрачностей, которые были в макете, — три уровня одного цвета:

| Уровень | Значение | Контраст на `#FFF9F7` |
|---|---|---|
| Основной | `#0E1736`, 100 % | 14.0 : 1 |
| Вторичный | `#0E1736`, 72 % | 6.8 : 1 |
| Приглушённый | `#0E1736`, 64 % | 5.3 : 1 |

Все три проходят WCAG AA для мелкого текста (порог 4.5 : 1).
Акцент `#DB404F` на розовом фоне даёт 3.5 : 1 — годится только для крупного текста
(от 24 px обычного или 19 px жирного), для мелкого текста его использовать нельзя.

## Что в палитру не входит

Эти цвета в макете есть, но приехали внутри вставленных блоков (карта, календарь,
футер) и в иконках соцсетей. Тиражировать их не нужно — при доработке макета
заменять на палитровые.

| Hex | Где встречается | Чем заменить |
|---|---|---|
| `#E4274D` | иконки соцсетей в hero и футере | фирменные цвета сервисов — оставить |
| `#17151D` | текст FAQ | `#0E1736` (уже заменено) |
| `#D9D9D9` | плейсхолдеры изображений | убрать вместе с заглушками |
| `#101010` 30 % | неактивные даты календаря | `#0E1736` 64 % |
| `#4D4D4D`, `#177EE6`, `#FF4433` | подписи и метки на карте | оставить — это рендер сервиса |
| `#3BA55D` | статус «на связи» в карточке менеджера | нужен токен `success`, если статус останется |
| `#EFE7E2`, `#FBF4ED` | подложка карты, карточка FAQ | `#FFF1F2` |

Отдельно: жёлтого `#FEBD1C` (звезда «5.0 Яндекс.Карты» из прошлой версии макета)
в текущем макете нет ни разу. Если звезда должна быть жёлтой — цвет нужно добавить
в палитру осознанно.
